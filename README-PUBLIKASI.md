# Pengumuman Kelulusan SDN 185/II Karya Harapan Mukti

## Cara Publikasi di GitHub Pages
1. Unggah isi folder ini ke repository GitHub baru.
2. Pastikan `index.html` dan folder `assets` berada di root repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch **main**, folder **/(root)**, lalu simpan.
5. Tunggu hingga tautan situs muncul di halaman Pages.

## Catatan
- File `.nojekyll` dapat tersembunyi di Finder karena diawali tanda titik. Di Mac tekan **Command + Shift + .** untuk menampilkannya.
- Tidak perlu mengunggah daftar siswa atau dokumen sumber ke repository.
- Situs statis tidak menyediakan keamanan penuh seperti server/database. Data login dalam aplikasi ini tidak ditulis sebagai daftar nama/NISN terbuka di kode publik.
